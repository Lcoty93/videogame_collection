# Video Game Collection

A full-stack MERN application for managing my personal game collection. Users can add, view, edit, and delete video games from their collections.

## Live Application
https://videogame-collection.onrender.com

<img width="1901" height="763" alt="image" src="https://github.com/user-attachments/assets/56745c91-0629-49e0-9c15-10fcab7336d8" />

## Coming soon
Version 2.0 is coming with an Admin role and guests can suggest new video games to play.

## Features

- View a collection of video games
- Add a new video game
- Edit an existing video game
- Delete a video game
- Track whether a game has been played
- Store application in MongoDB

## Technologies Used

### Frontend
- React
- React Router
- JavaScript
- HTML
- CSS

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose

### Deployment

- Render
- MongoDB Atlas
