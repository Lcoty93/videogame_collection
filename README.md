# Video Game Collection
A full-stack MERN application for browsing my personal video game library, view ratings, and recommend games for me to try.
An authenticated admin dashboard allows suggestions to be reviewed and approved directly into the collection or rejected.

## Live Application
https://videogame-collection.onrender.com

## Features

### Guest:
- View a collection of video games
- Suggest a video game
### Admin:
- Add a new video game
- Edit an existing video game
- Delete a video game
- Dashboard for viewing suggestions
- Accept or Deny suggestions
