# Video Game Collection

A full-stack MERN application for managing my personal game collection. Users can add, view, edit, and delete video games from their collections.

## Live Application
https://videogame-collection.onrender.com

<img width="1914" height="925" alt="image" src="https://github.com/user-attachments/assets/c3c568bd-070e-4be8-aae3-f4c33764bbaa" />


## Features

- View a collection of video games
- Add a new video game
- Edit an existing video game
- Delete a video game
- Track whether a game has been played
- Store application in MongoDB

## Technologies Used

### Frontend
- React
- React Router
- JavaScript
- HTML
- CSS

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose

### Deployment

- Render
- MongoDB Atlas
